# DarkestSpire
Darkest Dungeon characters for STS2


### How to create a character?
Please refer to `Characters/Example`.


### How to write `Local.props`?
Please refer to `Local.props.example`.
```HTML
<Project>
  <PropertyGroup>
    <Sts2Dir>请在此填入你的STS2目录</Sts2Dir>
    <RitsuLibDllPath>$(Sts2Dir)请在此填入你的 `STS2-RitsuLib.dll` 路径</RitsuLibDllPath>
  </PropertyGroup>
</Project>
```
